# ADR-0002：保留主动探测并永久禁止破坏性验证

- 状态：Accepted
- 日期：2026-07-10

## 背景

纯被动分析无法稳定确认 SQL 注入、XSS、SSRF 和越权等动态漏洞，但完全自主的攻击执行可能破坏真实业务。

## 决策

系统保留 L1 低影响主动探测和逐次批准的 L2 可回退探测。所有动作必须经过 SecurityPolicy。L3 破坏性动作永久拒绝，不能由模型或普通设置覆盖。

## 后果

- 能产生比静态分析更强的证据；
- 需要 scope、身份、预算、证据和清理模型；
- 部分高风险场景会输出 Inconclusive，而不是强行确认；
- 安全指标与检测指标具有同等验收地位。
